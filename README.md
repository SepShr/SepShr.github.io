This repository contains the source code for my personal website. It has been forked from [Sharu725's online-cv](https://github.com/sharu725/online-cv) repository. The website is hosted on GitHub Pages and can be accessed [here](https://sepshr.github.io/).

## Installation

* [Fork](https://github.com/sharu725/online-cv/fork) the repository
* Delete the `gh-pages` branch
* Re-create the `gh-pages` branch
* Go to settings and set Github Pages source as master.
* Your new site should be ready at `https://username.github.io/online-cv/`

Change all the details from one place: ``_data/data.yml``

Watch [this video](https://www.youtube.com/embed/T2nx6tj-ZH4) on installation.
